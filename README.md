# PT. Dirgantara Indonesia (PTDI) - AWS Real-Time Dashboard

Dashboard kontrol meteorologi real-time untuk Stasiun Meteorologi Bandara Husein Sastranegara / PTDI Bandung.

## 🚀 Fitur Utama
- **Monitoring Live Real-time:** Auto-refresh 30 detik untuk suhu, kelembapan, tekanan, dan presipitasi.
- **Profil Angin & Wind Rose:** Visualisasi kecepatan/arah angin bertingkat (10m, 80m, 120m, 180m) dan diagram Mawar Angin 16 sektor.
- **Prakiraan per Jam (BMKG Style):** Slider horizontal untuk prediksi cuaca 24 jam ke depan.
- **Banner Cuaca Dinamis:** Animasi visual cuaca (cerah, berawan, hujan) sesuai kondisi nyata.
- **Master Data Table & History Log:** Audit data mentah vs terjemahan dan opsi ekspor riwayat ke CSV.
